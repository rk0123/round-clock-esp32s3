# v2.9 发布说明

主题：**应用底键统一**、**录音与纪要都能在 TF 卡上浏览 / 播放 / 管理**。

> 本版同时包含 v2.8 tag 之后尚未发布的按钮与标题改动。

## 1. 应用底键与标题统一

- 小智 / 备忘 / 录音 / 待办四页底键统一到 **y=285、三槽 x=108/180/252、r=30、字号 16**，
  配色按语义固定：橙=开始、绿=确认、红=停止/危险、灰=次要。
- 标题从 16px 升到 **24px**（FONT24 补齐 11 个页面标题字，逐字校验覆盖）。
- 录音 / 听写等待时那根电平横条撤掉，改成主键外圈三段绿色流动弧；
  弧半径按槽位收敛，侧槽不会越出圆屏安全区。回放进度条保留。
- 小智主页的"绑定"键撤掉，绑定挪到设置页新增的 XIAOZHI 行（显示"去绑定 /
  待确认 / 已绑定"），主页只剩一颗居中主键。

## 2. 录音：浏览 / 播放 / 管理

录音仍是 `/REC/RECxxxx.WAV`（16k / 16bit / mono），TF 卡唯一数据源。

- 点主页文件名进列表；列表每次 4 条，**上下滑翻页，左右滑关闭列表**
  （与 Wi-Fi 列表同一约定）。
- 点条目**只选中**，不再一碰就播；三颗底键：
  - 左 **播放**（绿）：播放 / 停止当前选中段；
  - 中 **纪要 / 阅读**（灰）：没有纪要就生成，有纪要就直接打开阅读页；
  - 右 **删除**（红）：点一次变"确认"，再点一次才删，删除时同名纪要一并清掉。
- 已有纪要的条目右侧有**绿色小圆点**，不用点进去找。

## 3. 纪要：落盘 / 阅读 / 管理

- 云端纪要生成成功后由主循环写到 **`/REC/RECxxxx.TXT`**，与录音同编号，
  纯 UTF-8 文本，掉电不丢；写卡失败不影响界面上的结果显示。
- 阅读页按 7 行 / 页分页，上下滑翻页、左右滑关闭；底键为
  **上一页 / 下一页 / 删纪要**（单页时删除键自动居中）。
- 删除纪要点两次确认，**只删 TXT、保留 WAV**。
- 主页不再铺整段纪要（原来会压到底键），只显示"纪要已存卡 / 点阅读查看"；
  失败时显示一行错误摘要。

## 4. 验收

- 编译烧录通过：程序 49%，内部静态 77,688B，几何自检 **68 项 0 FAIL**。
- 真机截图：录音列表（四行 + 绿点 + 三键）、纪要阅读页（标题 / 分页 / 三键）、
  小智主页（绑定键已撤）、设置页 XIAOZHI 行。
- 同连接串口验收：列表翻页 1/3→2/3→1/3、`TAP` 选中后播放
  `/REC/REC0011.WAV`（16kHz mono）、删除后 11→10 段；
  纪要翻页 1/3→2/3→3/3→2/3、连点两次删除后 `[M]` 标记消失、录音保留。
- **真实云端链路**：`/REC/REC0009.TXT` 由 ASR + Qwen 生成并落盘（105 字符），
  说明生成 → 写卡 → 阅读闭环可用。
- 串口调试：`RECMREAD [n]` 从卡读纪要并打开阅读页、`RECMDEL [n]` 只删纪要、
  `RECMFAKE` 无网络时写示例纪要（验收 UI 用）；`RECLIST` 的 `[M]` 表示有纪要。

## 5. 已知限制

- 纪要生成依赖 Wi-Fi 和百炼 Key；词库、录音、回放、阅读本身完全离线。
- 本版未做 OTA、自动熄屏；录音列表上限 24 条（一页 4 条）。
