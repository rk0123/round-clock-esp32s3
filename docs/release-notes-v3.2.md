# v3.2 发布说明

主题：**播客页三键分工** —— 左右键只换集、`换源` 换节目、`更新` 把全部来源合成一张表。
顺带修掉喂 feed 时的两个隐性问题（NVS 写不下会静默丢光整份列表）。

## 1. 起因：一个键干了三件事

v0.27 起音乐页底部是两颗圆键：`曲库` + 一颗"看音源说话"的键 ——
TF 卡时是 `重扫`、播客时是 `更新`、电台时是 `切台`。

播客时这颗 `更新` 实际做的是「循环切下一档节目」，于是用户面对三个动作：

- 想听这一档的下一集 → **左右两颗大键**
- 想换一档节目 → 底部那颗 `更新`（名字根本看不出来是换源）
- 想把所有来源的新节目都拉一遍 → **没有入口**

`换源` 和 `换集` 名字只差一个字、职责完全不同，还共用同一片底部区域，必须拆开。

## 2. 三键布局

只在**播客音源**下变三键，其他音源维持原样：

| 音源 | 底部按键 | 圆心 |
|---|---|---|
| 播客 | `曲库` · `换源` · `更新` | `(112,292)` `(180,292)` `(248,292)` |
| 电台 / 音乐 | `曲库` · `切台` / `重扫` | `(118,292)` `(242,292)` |

三颗 `r=25`、圆心间距 68 → 净间隙 18 px，最远点 `(248+25, 292)` 距圆心 **145 < 158**，
不出安全区。触摸热区 `r=32`，`68 > 32+32=64`，三颗互不抢触摸。

> 圆屏上功能键一律 `fillCircle`：矩形胶囊的四个直角会和弧线打架。

## 3. `更新` = 合并全部来源

`更新` 不再是"切下一档"，而是真正把所有预置 feed 各拉一遍：

- 每档只取**最新 4 集**（`POD_REFRESH_PER_FEED`）→ 5 档共 20 条
- 按 **URL 去重**（同一集在镜像和原站都出现时只留一条）
- 标题前缀挂 **2 字节目简称**（无聊 / 谐星 / 李诞 / 忽左 / 沉浮），
  否则二十几条混在一起分不清出处
- 正在播的那一集尽量保持不动；如果它被新节目顶掉就停播
- `gPodMerged` 标志存 NVS（`podmg`），重启后曲库标题仍显示「全部来源」

曲库页标题随之区分：单档显示 `<节目名> n集`，合辑显示 `全部来源 n集`。

**进度提示**：抓取是同步的（占住 audioTask），5 档最长几十秒，不给反馈屏幕看着像卡死。
副信息行（y=244，16 号黄字）在任务期间替换成 `正在换源` 或 `更新全部来源 2/5`。
位置取 244 而不是原 250：16 号字高 16、底边 260，与底部圆键顶边（292−25=267）
才留得下 7 px 空隙。

## 4. 源变更：`feed.xyzfm.space` 被 IP 白名单挡了

小宇宙官方托管的 `feed.xyzfm.space` 现在对非白名单来源一律 **403**（本机和设备都中招）：

| 节目 | 处理 |
|---|---|
| 李诞 | 换 RSSHub 同节目路由 `65bb55f6513a776b57dedb32`，实测 200 / 15 集，节目不变只是换镜像 |
| 半拿铁·周刊 | 找不到可用镜像 → **摘除**，留着只会让 `更新` 每次白等十几秒超时 |

档数 6 → 5。`POD_FEED_COUNT` 同时从手写 `#define ... 6` 改成
`sizeof(POD_FEEDS)/sizeof(POD_FEEDS[0])` —— 旧写法加删一档忘了同步这个数就会越界读内存。

## 5. 顺带修掉的两个隐性问题

这两个不是用户直接看见的，但会让"更新"看起来时好时坏：

1. **`podSave()` 静默丢列表**。整份清单拼成一个 blob 写 `rcfg/podlist`，
   20 条 ≈ 5 KB，`putString` 写失败时**返回 0 而旧代码不检查**，库里就变成 0 条。
   现在改成 3 级降级重试（20 → 16 → 8 条），宁可少存几条也不整份丢干净，并打印截断条数。
2. **`podParseXml()` 写死 8 条且直写 `gPod`**。要合并多档就必须先把每档解析到临时区，
   直接写 `gPod` 会把上一档的结果冲掉。拆成 `podParseXmlTo(xml, dst, cap)` +
   `podFetchFeedInto(url, dst, cap)`，`podFetchFeed()` 退化成"抓到 `gPod` 就覆盖"。

顺手给 `strncpy` 补了显式收尾（`dst[n].name[len-1] = 0`）：标题变短时不会残留上一条的尾巴。

## 6. 串口命令

| 命令 | 变化 |
|---|---|
| `PODUPDATE` | **新增**：更新全部来源，各档最新 4 集合并去重 |
| `PODFEED [1..5 / URL]` | 范围从 `1..6` 收窄到 `1..5` |
| `AUD` | dump 增加一行 `PodFeed : <节目名/ALL SOURCES>  merged=YES/NO  job=0..2` |
