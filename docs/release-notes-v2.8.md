# v2.8 发布说明

主题：**返回交给手势**，背单词换衬线字体并支持发音。

## 1. 页面不再有返回键

撤掉所有页内返回按钮（功能页左上 `<`、设置页左上 `<`、城市列表 `< BACK`、
曲库 / 录音列表 / 配网页底部 `BACK`），标题栏和底栏留出的位置给内容。
备忘页那颗写着"返回"的键其实是"跳到清单"，现在统一叫"清单"。

返回只有一条路：

| 位置 | 手势 | 去哪 |
|---|---|---|
| 任意应用页 | 左右 / 下滑 | 应用中心 |
| 任意应用页 | 上滑 | 表盘 |
| 设置页 | 任意方向 | 进来时那一页 |
| 配网页列表态 | 左右滑 | 设置页（上下滑仍是列表滚动） |
| 配网页键盘态 | 任意滑动 | 取消输入，回列表 |
| 曲库浮层 | 左右滑 | 退出浮层（上下滑仍是翻页） |
| 其它子页 | 任意滑动 | 只关当前子页，不跳层 |

## 2. 表盘仍然是"一块页、两张脸"

模拟 / 数字**二选一**，同一时刻只显示选中的那一张，选择写 NVS `rcfg/face`。
设置页 FACE 行是正式入口；表盘点轴心 / 上滑是同一功能的快捷方式，改的是同一个值。

## 3. 背单词：衬线英文 + 发音

- 题干换成 **Georgia 30px 4-bit AA 衬线字**（`src/serif_font.cpp`，95 个 ASCII，
  单独编译单元），不再是原来无衬线的点阵英文。
- **发音**：右上角喇叭键开关（NVS `wd.pron`，默认开）。开关打开时，进入页面、
  切下一题、换词书会自动读一遍；点英文单词本身可随时重播（不受开关限制）。
  音源是有道词典的免密钥 `dictvoice` 接口（美音 type=2）。
  **发音需要 Wi-Fi**，没联网时静默跳过；词库本身仍然完全离线。
- 串口：`PRON` 报开关并强制读一遍，`PRON 0` / `PRON 1` 设置开关。

## 4. 验收

- `arduino-cli` 编译通过，烧录 COM12。
- 手势注入（`SWIPE x1 y1 x2 y2` 走真实触摸队列）逐项验证上表所有返回路径。
- 抓图确认九页无残留返回键、无重叠；`verify_apps_geometry.py` 68 项 0 FAIL。
- `FACE 0/1` 两张真机截图确认模拟 / 数字各自完整、互不叠加。

## 5. 已知限制

- 发音是网络调用，弱网 / 无网时不会出声；有道接口属于第三方服务，可能调整策略。
- 小智绑定子页仍需滑动关闭（此前按钮已在 v2.7 撤掉）。
