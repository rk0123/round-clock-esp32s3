# v2.8 发布说明

主题：**返回交给手势**，背单词换衬线字体并支持发音。

## 1. 页面不再有返回键

撤掉所有页内返回按钮（功能页左上 `<`、设置页左上 `<`、城市列表 `< BACK`、
曲库 / 录音列表 / 配网页底部 `BACK`），标题栏和底栏留出的位置给内容。
备忘页那颗写着"返回"的键其实是"跳到清单"，现在统一叫"清单"。

返回只有一条路：

| 位置 | 手势 | 去哪 |
|---|---|---|
| 任意应用页 | 左右 / 下滑 | 应用中心 |
| 任意应用页 | 上滑 | 表盘 |
| 设置页 | 任意方向 | 进来时那一页 |
| 配网页列表态 | 左右滑 | 设置页（上下滑仍是列表滚动） |
| 配网页键盘态 | 任意滑动 | 取消输入，回列表 |
| 曲库浮层 | 左右滑 | 退出浮层（上下滑仍是翻页） |
| 其它子页 | 任意滑动 | 只关当前子页，不跳层 |

## 2. 表盘仍然是"一块页、两张脸"

模拟 / 数字**二选一**，同一时刻只显示选中的那一张，选择写 NVS `rcfg/face`。
设置页 FACE 行是正式入口；表盘点轴心 / 上滑是同一功能的快捷方式，改的是同一个值。

## 3. 背单词：衬线英文 + 发音

- 题干换成 **Georgia 30px 4-bit AA 衬线字**（`src/serif_font.cpp`，95 个 ASCII，
  单独编译单元），不再是原来无衬线的点阵英文。
- **发音**：右上角喇叭键开关（NVS `wd.pron`，默认开）。开关打开时，进入页面、
  切下一题、换词书会自动读一遍；点英文单词本身可随时重播（不受开关限制）。
  音源是有道词典的免密钥 `dictvoice` 接口（美音 type=2）。
  **发音需要 Wi-Fi**，没联网时静默跳过；词库本身仍然完全离线。
- 喇叭图标不画外圈：开 = 亮黄喇叭 + 声波，关 = 灰色喇叭，点一下切换。
- 底部圆键半径 22 → 27：三字中文"下一题"此前会顶出圆边，现在完整落在圈内；
  "跳过"与"下一题"两态同尺寸，切换时不跳动。
- 串口：`PRON` 报开关并强制读一遍，`PRON 0` / `PRON 1` 设置开关。

## 4. 按钮与标题视觉统一（v2.8 收尾）

- **页面标题**升到 24px（FONT24 字库补齐全部标题字，缺字会静默画空白）。
- **四个应用底键统一**：小智 / 备忘 / 录音 / 待办全部落在同一排 y=285、
  同一套三槽 x=108 / 180 / 252、半径 30、字号 16，配色按语义固定：
  橙=开始（说话 / 录音 / 语音加）、绿=确认（清单 / 回放）、
  红=停止或危险（打断 / 清空）、灰=次要（纪要 / 翻页）。
  顺带修掉小智主键"把颜色值当 style 传、结果永远灰底"的 bug。
- **录音等待提示**：撤掉录音/听写时那个突兀的电平横条，改成按钮外圈三段
  绿色流动弧（半径按槽位收敛，侧槽 r-6 保证不越安全区）。回放进度条保留，
  那是"播到哪"不是"等识别"。
- **小智绑定挪进设置**：主页那颗非常用的"绑定"键撤掉，只在设置页新增
  XIAOZHI 行显示绑定状态（去绑定 / 待确认 / 已绑定），点它进绑定子页。
  主页现在只剩一颗居中主键，四页布局一致。
- 背单词/宠物页按各自内容密度处理：背单词两键保持 y=310（上方 2×2 选项
  占到 279，塞进 285 会重叠），配色统一；宠物四键排齐到 y=285，
  半径 20 保留（四键并排间距 48，放大必重叠）。

## 6. 已知限制

- 发音是网络调用，弱网 / 无网时不会出声；有道接口属于第三方服务，可能调整策略。
- 小智绑定子页靠滑动关闭；入口在设置页 XIAOZHI 行（主页已无绑定键）。
